These two are the most underrated facets Shodan exposes, and both answer a question that a port scan cannot:

- **JARM identifies the TLS implementation**, not the certificate. Many hosts serve a valid certificate from a CDN and still expose the fingerprint of whatever proxy is terminating TLS. It is how you count how many of "one service" are actually several different stacks.
- **The SSH fingerprint distribution is the "how many people reuse the same private key" chart.** A single popular fingerprint dominating means thousands of hosts share one key — which is both a security problem and a great way to fingerprint a scan.

For anyone doing asset inventory, these two facets convert a list of hosts into a list of *implementations*.

> Reproduce: `x shodan host count -f ssl.jarm 'port:443'` · `x shodan host count -f ssh.fingerprint 'port:22'`.
