这是 Shodan 提供的最被低估的两个 facet，而且都回答了端口扫描答不了的问题：

- **JARM 识别的是 TLS 实现，不是证书。** 很多主机从 CDN 拿一张合法证书，暴露出来的却仍是终结 TLS 的那个代理的指纹。它是数清「看起来是一种服务、其实是好几套协议栈」的办法。
- **SSH 指纹分布就是「有多少人复用同一把私钥」那张图。** 某一个指纹占比很大，意味着成千上万台主机共用一把密钥 —— 这既是安全问题，也是给扫描流量做指纹的绝佳手段。

对做资产盘点的人来说，这两个 facet 把一份主机列表变成了**一份实现清单**。

> 复现：`x shodan host count -f ssl.jarm 'port:443'` · `x shodan host count -f ssh.fingerprint 'port:22'`。
